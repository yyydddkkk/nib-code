# nib 0.22.1

- Run syntax errors can mark the reported column in a bounded, credential-masked source excerpt. If a `rerun` patch is rejected, the error identifies which edit failed and why; no script runs.
- `tools.wait()` returns structured exit codes and timeout details for background Bash commands, even when the displayed output is truncated. If the masked full output was saved, the result also includes its file path. Short completion text stays compatible.

# nib 0.22.1（中文）

- Run 遇到语法错误时，可在长度受限且已遮蔽凭据的源码片段中标出报错列。如果 `rerun` 补丁被拒绝，错误会指出哪一条编辑失败及其原因，不会执行脚本。
- `tools.wait()` 直接返回后台 Bash 命令的退出码和超时信息，即使展示的输出被截断也不受影响。如果已保存脱敏后的完整输出，结果还会包含文件路径。短输出的原有格式保持不变。
