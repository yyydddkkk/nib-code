# nib 0.16.1

GPT-6.2 support for Codex and OpenAI.

- Add `gpt-6.2-sol` and `gpt-6.2-astra` to both model catalogs. Both services now default to GPT-6.2 Sol; explicitly configured models remain unchanged, and older models are still available.
- Use Codex's backend context windows: 500,000 tokens for Sol and 272,000 for Astra. Both OpenAI API models use a 1,050,000-token context window and support up to 128,000 output tokens.
- Both GPT-6.2 models reject reasoning effort `none`. The `off` setting and context compaction use the minimum `low` reasoning effort.

# nib 0.16.1（中文）

Codex 和 OpenAI 新增 GPT-6.2 支持。

- 两个服务的模型列表均新增 `gpt-6.2-sol` 和 `gpt-6.2-astra`，默认模型改为 GPT-6.2 Sol。已有配置显式指定的模型不变，旧模型仍可选择。
- 使用 Codex 后端的上下文窗口：Sol 为 500,000 token，Astra 为 272,000 token。OpenAI API 的两款模型均使用 1,050,000 token 上下文窗口，最多支持 128,000 输出 token。
- 两款 GPT-6.2 模型均不接受推理级别 `none`；`off` 设置和上下文压缩使用最低 `low` 推理级别。
