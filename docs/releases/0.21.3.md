# nib 0.21.3

- Markdown tables now use bold headers, a subtle horizontal rule, and muted column dividers. Long cells wrap within their columns, and tables that are too wide for the terminal become labeled records instead of showing raw Markdown.

---

# nib 0.21.3（中文）

- Markdown 表格现在使用加粗表头、淡色表头横线和淡色列分隔线。较长的内容会在单元格内换行；终端太窄时，表格会按记录显示带标签的字段，不再露出 Markdown 源码。
