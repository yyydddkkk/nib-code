# nib 0.21.1

- Input prediction suggests natural follow-ups based on the user's goal and the state of the task, even if the user hasn't spelled out the next step. Suggestions are written from the user's perspective, not the agent's.
- When there is no likely reply, the input stays empty. The predictor no longer tries to invent a polite acknowledgment after a completion report or make an arbitrary choice for the user.

- 输入预测会根据用户的目标和任务进度建议自然的后续消息，即使用户没有明确说出下一步。建议以用户的口吻撰写，而不是以 agent 的口吻撰写。
