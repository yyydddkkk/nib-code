# nib 0.20.0

This release makes omitted tool output easier to inspect and speeds up searches for rare identifiers.

- When a Run or background task output is shortened for display, nib saves up to 16 MiB of the original output in the Session and shows its path so the agent can inspect it without rerunning the command.
- `tools.grep` can skip files that lack a required literal for case-sensitive whole-word and simple anchored regex searches.
- GPT-6.2 and newer models on Codex and OpenAI Responses send the reusable system prompt in the cacheable input prefix.
- Use `/compact [focus]` to tell manual compaction which context to retain.
- If `tools.edit` cannot find the requested text, its error can point to a nearby matching line and report whether the file changed since the last read or write.

# nib 0.20.0（中文）

本版本让工具输出中被省略的内容更容易查看，也加快了对少见标识符的搜索。

- Run 或后台任务的输出因显示限制被截短时，nib 会在会话目录中保存最多 16 MiB 的原始输出并显示路径，代理可直接查看，无需重跑命令。
- 对于区分大小写的整词匹配和简单的行首锚定正则，`tools.grep` 可以跳过不含必需文本的文件。
- 通过 Codex 和 OpenAI Responses 使用 GPT-6.2 及更新模型时，可复用的系统提示词会放入可缓存的输入前缀。
- 使用 `/compact [focus]` 可以指定手动压缩时要保留的上下文重点。
- `tools.edit` 找不到待替换文本时，错误信息可以提示相近文本的行号，以及文件自上次读取或写入以来是否发生变化。
