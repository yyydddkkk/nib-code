# nib 0.25.0

- **Install and update on Windows x64.** The PowerShell installer verifies the release ZIP and installs without administrator privileges. Use the installer to upgrade from 0.24.0; from 0.25.0 onward, `nib update` can replace the running executable and keeps one backup. See the [Windows preview guide](https://github.com/yyydddkkk/nib-code/blob/v0.25.0/docs/windows-cli-preview.md).
- **Run tools from a specific directory.** A `// @cwd:` directive on the first line sets the Run's working directory for relative file, search, and Bash paths without changing the Session directory or sandbox write permissions. Background Runs and reruns keep that directory.
- **See what happened when a Run finishes.** Failed Runs list confirmed changes made by `tools.write` and `tools.edit`. Run output also flags Bash timeouts and nonzero exits without changing JavaScript success semantics. Offline replay preserves the original summaries.
- **A new activity indicator.** The TUI shows an orbital animation on terminals that support Kitty graphics and keeps the text spinner elsewhere, during retries, and during long waits.

# nib 0.25.0（中文）

- **在 Windows x64 上安装和更新。** PowerShell 安装脚本会校验发布 ZIP，无需管理员权限。从 0.24.0 升级请使用安装脚本；从 0.25.0 起，`nib update` 可替换正在运行的可执行文件，并保留一份备份。详情见 [Windows 预览版指南](https://github.com/yyydddkkk/nib-code/blob/v0.25.0/docs/windows-cli-preview.md)。
- **在指定目录中运行工具。** 在首行写入 `// @cwd:` 指令，为 Run 中的相对文件路径、搜索路径和 Bash 路径指定工作目录，不改变会话目录或沙箱写入权限。后台 Run 和重新运行都会保留该目录。
- **在 Run 完成后查看实际结果。** 失败的 Run 会列出由 `tools.write` 和 `tools.edit` 造成的已确认文件变更。Run 输出也会提示 Bash 超时和非零退出，但不会改变 JavaScript 的成功判定。离线回放会保留原始摘要。
- **新的活动指示器。** 在支持 Kitty 图形协议的终端上，TUI 会显示轨道动画；其他终端以及重试或长时间等待时仍使用文本转轮。
