# nib 0.26.0

- **Shorter Run titles.** Run blocks lead with the tools or paths they show instead of repeating `Run`. When no tool or path is known yet, `Run` remains the fallback.
- **Color to guide your eye.** Tool names, filenames, and displayed commands use terminal cyan. The activity icon is blue in both the orbital animation and the text spinner; the adjacent status text keeps its existing colors, including yellow warnings.

---

# nib 0.26.0（中文）

- **更简洁的 Run 标题。** Run 块直接显示工具或路径，不再重复 `Run` 前缀。尚无工具或路径信息时，仍用 `Run` 作为默认标题。
- **用颜色突出关键信息。** 工具名、文件名和界面中显示的命令使用终端青色。轨道动画和备用转圈字符都改为蓝色；旁边的状态文字颜色不变，包括黄色警告。
