# nib 0.21.4

- Run blocks use a subtler hover highlight in both Normal and Simple mode. Menu highlights are unchanged.
- The `tools.fetch` example shows how to keep successful results when independent requests run in parallel, while reporting rejected requests and non-2xx responses separately.
- Both READMEs now lead with charts for memory use, prompt length, and the same-model comparison with Codex CLI, in that order.

# nib 0.21.4（中文）

- 普通模式和简洁模式下，Run 块的鼠标悬停高亮都更淡了，菜单高亮保持不变。

- 中英文 README 都在开头依次展示内存占用、提示词长度和与 Codex CLI 的同模型对比图。
