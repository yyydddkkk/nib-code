# nib 0.23.0

- **Windows x64 CLI preview.** Verify `nib-x86_64-windows-preview.zip` against `SHA256SUMS`, then extract `nib.exe`. The preview supports `nib ask`, `nib js`, file tools, and session resume. `tools.bash` uses Git Bash from the default system-wide Git for Windows install, even when nib is launched from PowerShell. Windows Job Objects clean up descendants on exit, timeout, or cancellation; Ctrl+C saves the interrupted turn for resume. The interactive TUI and `workspace` write isolation are not included. See the [preview guide](https://github.com/yyydddkkk/nib-code/blob/v0.23.0/docs/windows-cli-preview.md) for setup and limitations.
- `/provider` now identifies when nib reuses a Codex CLI login. A fresh nib home can use that login without copying credentials or saving provider settings.

# nib 0.23.0（中文）

- **Windows x64 CLI 预览版。** 用 `SHA256SUMS` 校验 `nib-x86_64-windows-preview.zip`，再解压出 `nib.exe`。预览版支持 `nib ask`、`nib js`、文件工具和会话恢复。即使从 PowerShell 启动 nib，`tools.bash` 也会使用 Git for Windows 默认系统安装位置的 Git Bash。Windows Job Object 会在退出、超时或取消时清理后代进程；按 Ctrl+C 会保存中断的 Turn，便于恢复。暂不包含交互式 TUI 和 `workspace` 写入隔离。安装方式和限制见[预览版指南](https://github.com/yyydddkkk/nib-code/blob/v0.23.0/docs/windows-cli-preview.md)。
- nib 复用 Codex CLI 登录时，`/provider` 现在会标明凭据来源。全新的 nib 数据目录也能复用该登录，无需复制凭据或保存 provider 设置。
