# nib 0.24.0

- **The Windows x64 preview now includes the native TUI.** Download `nib-x86_64-windows-preview.zip`, verify it against `SHA256SUMS`, and run `.\nib.exe` in Windows Terminal. No WSL is required. Native ConPTY tests cover keyboard editing, Unicode multiline paste without auto-submission, resizing with a draft, and clean exit.
- Use `/provider` to set an API key or sign in to Codex with a device code on Windows. Browser callback sign-in, clipboard images, and `workspace` write isolation are still unavailable. `tools.bash` still requires Git for Windows. See the [Windows preview guide](https://github.com/yyydddkkk/nib-code/blob/v0.24.0/docs/windows-cli-preview.md) for setup and other limitations.

# nib 0.24.0（中文）

- **Windows x64 预览版现已包含原生交互式 TUI。** 下载 `nib-x86_64-windows-preview.zip`，用 `SHA256SUMS` 校验后解压，在 Windows Terminal 中运行 `.\nib.exe`，无需 WSL。原生 ConPTY 测试覆盖了键盘编辑、多行 Unicode 粘贴不会误提交、缩放时保留草稿以及正常退出。
- 在 Windows 上，可以用 `/provider` 设置 API 密钥，或通过设备码登录 Codex。暂不支持浏览器回调登录、剪贴板图片和 `workspace` 写入隔离。`tools.bash` 仍需要 Git for Windows。安装方式和其他限制见 [Windows 预览版指南](https://github.com/yyydddkkk/nib-code/blob/v0.24.0/docs/windows-cli-preview.md)。
