# nib 0.16.0

Lower-overhead file reads and tool execution recording, with rebuildable Session metrics for local analysis.

## Recording and replay

- Full tool argument/result sidecar recording is now off by default. Set `NIB_RECORD=on` to enable it or `NIB_RECORD=off` to disable it. Existing explicitly set legacy values retain their behavior; values are case-sensitive.
- Main Session logs, resume, timing and byte metrics remain available without sidecar recording. Existing recordings remain replayable regardless of the recording switch. Enabling recording on resume captures subsequent Runs only; earlier tool returns cannot be reconstructed.
- Recording encodes JSON directly into the Run buffer, removing an intermediate allocation and copy while preserving recording bytes, deduplication and replay behavior. Encoding failures leave no partial record and do not truncate results delivered to JavaScript.
- An allocation failure while handing off Run images no longer loses ownership of the Run outcome.

## File reads

- Paginated reads scan with a bounded buffer and retain only the requested lines instead of allocating the entire file. Regular files can stop after the requested page and lookahead; reads near EOF still scan the prefix.
- Existing line, newline, pagination and size-limit semantics are preserved. Reads reject observed file changes before refreshing stale-write protection.

## Local analysis and measurement

- `python3 scripts/stats_db.py` builds an optional, disposable SQLite metrics index from Session logs using Python's standard library. It skips unchanged sources and transactionally replaces changed files without copying message bodies, scripts, tool arguments/results or diagnostic messages. JSONL remains authoritative; nib gains no runtime database dependency.
- Metrics cover Steps, foreground/background Runs, tool calls and diagnostics, including tool-delivery completions and model switches before the first Step.
- A model-free ReleaseFast benchmark measures native scheduling, recording and JavaScript bridging. Probes are compile-time disabled in normal builds. Reproduction commands, measurements and limitations are documented; no worker pool or scheduler policy change is enabled.

# nib 0.16.0（中文）

降低文件读取和工具执行录制的开销，并提供可重建的 Session 指标索引用于本地分析。

## 录制与回放

- 完整工具参数／结果的 sidecar 录制改为默认关闭。设置 `NIB_RECORD=on` 可启用，`NIB_RECORD=off` 可关闭。其他显式设置的历史值保留原有行为；取值区分大小写。
- 不开启 sidecar 录制仍保留主 Session 日志、会话恢复、计时和字节指标。已有录制不受开关影响，仍可回放。恢复会话时开启录制只记录后续 Run，无法重建此前的工具返回值。
- 录制时直接将 JSON 编码进 Run 缓冲区，省去一次中间分配和复制，同时保持录制字节、去重和回放行为不变。编码失败不会留下半条记录，也不会截断传给 JavaScript 的工具结果。
- 修复移交 Run 图片时分配失败导致 Run 结果失去所有权的问题。

## 文件读取

- 分页读取改用固定大小缓冲区扫描，只保留请求的行，不再分配整个文件。普通文件读取到所需页面及后续探测字节后即可停止；靠近 EOF 的请求仍需扫描前面的内容。
- 保持既有的行、换行、分页和大小限制语义。检测到文件变化时读取失败，不刷新用于防止陈旧覆盖的文件版本记录。

## 本地分析与测量

- `python3 scripts/stats_db.py` 使用 Python 标准库，将 Session 日志构建为可选、可丢弃的 SQLite 指标索引。跳过未变化的源文件，以事务方式替换变化文件的指标，不复制消息正文、脚本、工具参数／结果或诊断消息。JSONL 仍是权威存储，nib 不增加运行时数据库依赖。
- 指标覆盖 Step、前台／后台 Run、工具调用和诊断，包括 tool-delivery 模式下的完成事件，以及首个 Step 前切换模型的情况。
- 新增无需模型的 ReleaseFast 基准，测量原生工具调度、录制和 JavaScript 桥接。正式构建在编译期禁用探针，并提供复现命令、测量结果及限制说明；未启用线程池或改变调度策略。
