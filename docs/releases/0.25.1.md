# nib 0.25.1

- **Smaller context after compaction.** nib budgets the next request toward 10% of the context window while keeping the latest user instructions and complete tool call/result groups. Large recorded tool results can be reopened from a short reference without rerunning the tool. Later compactions update the existing handoff instead of stacking summaries.
- **Smoother activity animation.** On Kitty-graphics terminals, the orbital indicator stays visible while streamed text redraws. Its particles are easier to see, and it clears when the activity ends.

# nib 0.25.1（中文）

- **压缩后保留更少的上下文。** nib 以窗口的 10% 作为下一次请求的软目标，同时保留最新的用户要求，并保持工具调用和结果成组。较大的已记录工具结果可以通过简短引用重新读取，无需重新运行工具。后续压缩会更新已有交接摘要，不再叠加摘要。
- **活动动画更稳定。** 在支持 Kitty 图形协议的终端上，流式文本重绘时，轨道活动指示器会保持可见。粒子更醒目，活动结束后指示器会清除。
