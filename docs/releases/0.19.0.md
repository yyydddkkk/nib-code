# nib 0.19.0

Codex Fast is available for supported GPT models, and cross-model resume makes it easier to see which Session Profile is still in effect.

- Use `/fast` to toggle the saved Codex Fast setting. Supported models request the priority tier over WebSocket or SSE, including after transport fallback. Normal mode shows the requested tier; the Simple-mode input border stays plain.
- After resuming with a model that selects a different adaptation, `/status` shows the retained Session Profile. Resume still preserves the original system prompt and Tuning.
- Forked Sessions using tool delivery can now call `tools.wait()` as their prompt describes. Ordinary child Sessions still wait without that tool.
- Prompt rendering now uses named inputs without changing the rendered text. Profile overrides remain experiment switches rather than persistent user settings.

# nib 0.19.0（中文）

支持的 Codex GPT 模型现在可以使用 Fast 模式；跨模型恢复后，也更容易看出当前会话仍沿用哪份 Profile。

- 使用 `/fast` 切换并保存 Codex Fast 设置。支持的模型会通过 WebSocket 或 SSE 请求优先服务层级，传输回退后也会保留请求。普通模式显示所请求的层级，简洁模式的输入边框保持原样。
- 换用适配策略不同的模型恢复会话后，`/status` 会显示沿用的会话 Profile。恢复仍保留原系统提示词和 Tuning。
- 使用工具投递的分叉会话现在可以按提示词说明调用 `tools.wait()`；普通子会话仍不使用该工具等待。
- 提示词渲染改用具名输入，渲染文本不变。Profile 覆盖仍仅用于实验，不成为持久用户设置。
