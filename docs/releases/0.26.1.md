# nib 0.26.1

- **One-line Windows installation.** The Windows x64 preview now uses a single PowerShell command in the README. It uses the existing installer and ZIP format.
- **Cleaner shell task rows.** Numbered shell tasks show the command directly after the ID, without a duplicate `bash` label. Only the first command word is cyan.
- **Correct `wait` labels.** Run summaries and Session timing logs now label `tools.wait()` as `wait` instead of `unknown`.

# nib 0.26.1（中文）

- **Windows 一行安装。** README 现在只需一条 PowerShell 命令即可安装 Windows x64 预览版。安装脚本和发布 ZIP 的打包方式不变。
- **更简洁的终端任务行。** 带编号的任务直接在编号后显示命令，不再重复添加 `bash` 标签。只用青色突出命令的第一个词。
- **修正 `wait` 标签。** Run 摘要和 Session 计时日志现在将 `tools.wait()` 显示为 `wait`，不再显示为 `unknown`。
