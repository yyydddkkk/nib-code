# nib 0.21.0

This release makes Bash timeouts easier to recover from and gives context compaction a more predictable budget for recent history.

- `tools.bash` now returns `timed_out: true` with the captured output and elapsed time instead of rejecting on timeout. Timed-out background commands still report failure.
- Pass `cwd` to run a Bash command from a different directory. Relative paths resolve from the Session directory, and the command does not gain any additional sandbox permissions.
- Context compaction budgets for the summary and pending input before choosing how much recent history to keep verbatim. It keeps complete Steps together, including their tool results, and summarizes even the newest Step if it cannot fit. Original messages remain in the Session log.
- Input predictions now stay in the user's voice, and sent messages in the terminal have a subtler background and more vertical padding.

# nib 0.21.0（中文）

本版本让 Bash 命令超时后更容易恢复，也让上下文压缩保留多少近期历史更可预测。

- `tools.bash` 超时时不再拒绝调用，而是返回 `timed_out: true`、已捕获的输出和耗时。超时的后台命令仍会被标记为失败。
- 可通过 `cwd` 指定单条 Bash 命令的工作目录。相对路径以会话目录为基准，命令不会因此获得额外的沙箱权限。
- 上下文压缩会先为摘要和待处理输入预留空间，再决定原样保留多少近期历史。每个 Step 及其工具结果会一并保留；如果连最新的 Step 也放不下，就将其纳入摘要。原始消息仍保存在会话日志中。
- 输入预测会用用户的口吻续写；终端里已发送消息的背景色更淡，上下也留出了更多空间。
