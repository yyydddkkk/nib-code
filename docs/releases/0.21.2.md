# nib 0.21.2

- Codex and other Sessions using user-message delivery can now wait for a specific background task by ID and continue working in the same turn, without first sending a reply. Results returned by `tools.wait()` are not sent again; unclaimed results still arrive automatically.

---

# nib 0.21.2（中文）

- Codex 以及其他使用用户消息投递结果的会话，现在可以按 ID 等待指定的后台任务，并在同一轮继续工作，无需先发一条回复。`tools.wait()` 已返回的结果不会重复投递；未主动领取的结果仍会自动送达。
