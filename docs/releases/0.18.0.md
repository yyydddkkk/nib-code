# nib 0.18.0

nib now separates shared behavior from model-family adaptations. Unadapted models use the shared defaults without changing the model or Provider you selected.

- Session logs distinguish the detected model family from the applied Profile. GPT, Claude, and DeepSeek resolve to their family Profiles; Gemini and unrecognized model names use the default. Detecting Gemini does not add a native Gemini Provider.
- Background result delivery, tool availability, and waiting instructions use the same Session setting. DeepSeek's default no-validation strategy no longer picks up full-validation advice from the bash tool description. Resumed Sessions keep their original system prompt and logged strategy.
- The README reports about 1.5k tokens of shared prompt text. The benchmark documentation reports full fixed-input estimates separately and includes a command to reproduce both measurements offline.
- Local developer installs now build from the committed revision of the local `dev` branch, leaving the stable `nib` binary untouched. Skill completion shows all matches, with scrolling when needed.

# nib 0.18.0（中文）

nib 将通用行为与模型家族适配分开。尚未适配的模型使用通用默认策略，不会改变你选择的模型或服务。

- 会话日志分别记录识别出的模型家族和实际采用的 Profile。GPT、Claude 和 DeepSeek 使用各自家族的 Profile；Gemini 和无法识别的模型名使用通用策略。识别 Gemini 不代表新增了原生 Gemini 服务。
- 后台结果投递、工具可用性和等待提示使用同一项会话策略。DeepSeek 默认不附带验证建议，`bash` 工具说明也不再额外要求完整验证。恢复会话时保留原系统提示词和记录中的策略。
- README 报告约 1.5k tokens 的通用提示词。基准测试文档另列各代表性请求的完整固定输入估算，并提供离线复测命令。
- 本地开发安装改为从本地 `dev` 分支的已提交版本构建，不覆盖稳定版 `nib`。技能补全会显示全部匹配项，列表过长时可以滚动。
