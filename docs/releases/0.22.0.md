# nib 0.22.0

- **Pages is a new, optional TUI view.** Start with a centered, borderless prompt. On send, the prompt rises and widens into the heading for a page that contains only that Turn. Use Left and Right to browse Turns; use Up and Down to scroll within a page. Activity stays under the heading and the page number stays at bottom right.
- Press Esc to set aside a draft without sending it or stopping the active Turn. Return to the draft to pick up at the same cursor position. Ctrl+S cycles Normal → Simple → Pages → Normal and remembers your choice. `/pages` switches directly to Pages.
- Run output masks recognized credentials before display or logging. The Bash tool documentation also clarifies how exit status is reported for independent checks.

# nib 0.22.0（中文）

- **Pages 是新增的可选 TUI 视图。** 从屏幕中央的无框提示符开始。发送时，输入向上移动并向两侧展开，成为页首标题。每页只显示一个 Turn。左右键翻页，上下键在页内滚动。运行状态在标题下方，页码在右下角。
- 按 Esc 可暂存草稿，不会发送消息，也不会停止正在运行的 Turn。回到草稿时，光标会留在原处。Ctrl+S 按 Normal → Simple → Pages → Normal 循环切换并记住选择。`/pages` 可直接进入 Pages。
- Run 输出会在显示或写入日志前遮蔽能识别的凭据。Bash 工具文档也进一步说明了多项独立检查的退出状态如何报告。
