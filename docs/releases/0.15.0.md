# nib 0.15.0

Change-first Run details, cross-provider model selection, and a quieter TUI.

## Runs and script repair

- Opened Runs put file changes first. Files expand independently; a single file with at most 20 recorded diff lines opens by default. Larger or multi-file changes start closed, and expanded files retain their recorded diffs, colors and intraline emphasis.
- Result and Script sit behind a muted Details disclosure. Failures, warnings and caught tool errors open Details and Result by default unless explicitly closed. Long results have a labeled first-20-line preview and a full-result toggle; Script starts closed. Successful edit/write-only Runs still show Changes only.
- Nested disclosure choices survive parent closure, resize and Normal/Simple switches. Output and script remain selectable in the default foreground.
- Failed scripts can be repaired with exact replacement edits against a Session-scoped source reference. A repair starts a new Run from the beginning, so earlier effects may repeat. Original sources and results remain unchanged; resume and offline replay retain the executed source.

## Models

- `/model` lists built-in catalogs and configured models across configured or signed-in services, including custom endpoints and the active model. Filter by model name or `service/model`; selecting a row switches both service and model.
- Model menus put model names first, with aligned provider and current-model columns. Keyboard selection highlights the full row independently of the current-model label. Direct `/model <model>` still selects a model of the current service.

## Interface

- The rounded input frame keeps its height, adds two columns of inner padding on each side, and right-aligns model/context metadata. Simple mode retains its quiet metadata policy.
- File lists align nonzero change counts by terminal display width when space permits, with muted directories, readable filenames and colored additions/removals. Long paths in Run details wrap rather than forcing aligned columns.
- Markdown headings use bold default foreground instead of blue.
- Turn footers show elapsed time only, sharing the row with the change summary when it fits. `/status` retains Run/Step counts, tokens, tool data, timing and cache details.

# nib 0.15.0（中文）

优先展示变更的 Run 详情、跨服务商模型选择，以及更简洁的 TUI。

## Run 与脚本修复

- 展开的 Run 优先显示文件变更，各文件可独立展开。只有一个文件且记录的 diff 不超过 20 行时默认展开；较大或多文件变更默认折叠。展开后保留记录的 diff、颜色及行内差异强调。
- Result 和 Script 收入低对比度的 Details 折叠项。失败、警告和被捕获的工具错误默认展开 Details 和 Result，除非用户明确关闭。长结果提供标明范围的前 20 行预览，并可切换完整结果；Script 默认折叠。成功且只包含 edit/write 的 Run 仍然只显示 Changes。
- 关闭父级、调整窗口大小或切换普通／Simple 模式时，保留各层展开状态。输出与脚本使用默认前景色，文字仍可选择复制。
- 失败脚本可通过 Session 范围内的源码引用和精确替换进行修复。修复会新建 Run，从脚本开头执行，因此先前的副作用可能重复。原始源码和结果保持不变；恢复会话及离线回放保留实际执行的源码。

## 模型

- `/model` 汇总已配置或已登录服务的内置模型目录和已配置模型，包括自定义端点及当前模型。可按模型名或 `service/model` 筛选；选择一项会同时切换服务商和模型。
- 模型菜单先显示模型名，再以对齐列显示服务商与当前模型标记。键盘选中项整行高亮，与当前模型标记相互独立。直接输入 `/model <model>` 仍选择当前服务的模型。

## 界面

- 圆角输入框保持原有高度，左右各留两列内边距，模型与上下文信息靠右对齐。Simple 模式保留其简洁的元信息策略。
- 空间足够时，文件列表按终端显示宽度对齐非零变更计数；目录弱化、文件名保持清晰，新增与删除使用对应颜色。Run 详情中的长路径通过换行显示，不强行对齐列。
- Markdown 标题改为默认前景色加粗，不再使用蓝色。
- Turn 页脚只显示耗时；空间足够时与变更摘要共用一行。Run／Step 数量、token、工具数据量、计时和缓存详情保留在 `/status`。
