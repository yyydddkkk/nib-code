# 0016 race：用户授权预算，模型选择分支

## 决定

`/race` 是默认关闭、不持久化的进程内授权；用户决定是否允许花多份额度，模型决定是否调用 `tools.race` 以及各分支的 prompt。工具说明与 system 不随开关变化；状态通过下一条用户输入前的事实消息传入。仅根会话可调用，所有分支是 fork 子会话，不能再委派。有效配置中的 `race_branches`（默认 3，2–8）传给子会话。

## 隔离与起点

同目录 fork 无法安全比较不同实现：写文件、构建与删除会互相污染。因此每个 race 创建一个私有起点提交和每分支一个 detached git worktree，放在 NIB_HOME 下。通过独立临时 index 从父仓库 HEAD 捕获当前 tracked 文件和非 ignored untracked 文件，不修改父 index、HEAD 或 refs；分支只看到这个快照。仓库子目录启动时保留相对 cwd。拒绝非仓库；当前安全拒绝无 HEAD、symlink、submodule、sparse checkout、冲突 index、非 UTF-8 路径和特殊文件，不静默丢文件或把不能精确复制的状态当作起点。支持这些结构前需要补齐快照、应用与清理测试；特别是绝对 symlink 可能重新指向父目录，不能仅依靠普通 checkout 就声称隔离。工作树不是恶意代码安全边界。git 文件系统事务由嵌入的 Python 3 标准库 helper 执行（Git 调用不经 shell、不运行 hooks/filters 或用户提交签名程序，应用时禁用外部 merge driver），Zig 持有生命周期锁并管理进程取消。使用 race 需要 git 和 python3；缺少依赖按执行失败返回数据，普通会话不依赖该 helper。

worktree 生命周期由 race 所有；所有退出路径先停止并 join 分支（复用 agent/process 的取消与进程组清理），再移除 worktree。残留目录有独占进程锁/所有权标识，启动清理只清死进程残留，不能删除其他仍运行的 nib 的 race。

## 路径兼容

fork 保留父 system/history 字节，不能重写历史中的绝对路径以免破坏缓存与 reasoning。read/edit/write/grep/glob 将父项目根下的绝对路径按路径边界映射到分支 worktree；bash 在相应 worktree cwd 执行，命令文本含父项目绝对根路径即拒绝并提示相对路径。合成 fork tool result 告知 race 身份、路径与映射。此方案不约束恶意 shell 或外部路径，见 compromises。

## 胜出、应用与并发

子会话 ok 后再在对应 worktree 运行可选 verify，退出 0 才成为候选。第一个通过者锁定后立即取消其余并 join；所有分支用量包括失败/被停止的分支均入账。全部失败不更改父工作区。

胜者工作树相对私有起点导出 binary patch，包含新增/删除。先在隔离的临时 index/工作树中，将父工作区当前状态与胜者按起点三方合并；冲突时保存 patch 并返回路径，父目录和父 index 不变。应用前重查父文件状态；有并发变化则拒绝。应用阶段保存受影响路径的旧内容，并在失败时回滚，不能留下部分应用。不可控外部写入者不参与锁，无法提供操作系统级跨文件事务；测试覆盖正常冲突与失败回滚，未来可用文件系统快照强化。应用成功按真实 diff 记入父 Run changes（包括 shell 改动）。

## 可见性与置信度

树显示分支 aN/race 和 won、stopped、failed；race 日志包含分支 id、耗时、usage、胜者与应用状态，stats 汇总次数、胜出延迟与累计用量。

高置信度：本地 git 快照、binary diff、独立 index、取消进程组、固定 schema 可用 mock 与临时仓库验证。中等置信度：多实现赛跑缩短延迟的实际收益与验证命令的判别力；验证通过不等于语义正确，race 不保证收益。较低置信度：服务端对 fork 前缀的缓存命中；沿用 fork ADR 的条件，不作命中承诺。
